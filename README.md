# Facebook-analysis-Machine-Learning-

## Overview
This project analyzes Facebook Live Sellers data to understand how different
content formats and posting times influence user engagement. The analysis focuses
on key engagement metrics such as reactions, comments, and shares to derive
actionable insights for content strategy optimization.

## Objective
- Analyze user engagement patterns across different post types
- Identify optimal posting times for higher audience interaction
- Examine relationships between reactions, comments, and shares
- Provide data-driven recommendations to improve content performance

## Dataset
The dataset contains Facebook Live Sellers post-level data, including:
- Post type (Photo, Video, Status, Link)
- Posting time information
- Engagement metrics (reactions, comments, shares)

## Methodology
- Data cleaning and preprocessing using Pandas
- Exploratory Data Analysis (EDA) to identify trends and patterns
- Correlation analysis between engagement metrics
- Visualization of engagement behavior by post type and posting time

## Key Insights
- **Video posts** generated the highest number of comments and shares, making
  them the most effective format for deep engagement
- **Evening posting hours** consistently resulted in higher audience interaction
- **Comments showed a strong positive correlation with shares**, indicating that
  discussion-driven content is more likely to be widely shared
- Photos and videos dominated engagement, while link posts showed minimal impact

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Outcome
This project demonstrates how exploratory data analysis can be used to extract
meaningful insights from social media data and inform content strategy decisions.
The findings highlight the importance of content format and timing in maximizing
user engagement on Facebook Live.
